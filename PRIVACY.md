# Privacy / 개인정보

**English.** AI Chat Easy runs entirely in your browser. It has no server, no analytics and no tracking. It reads the chat input only when you use one of its tools (for example to copy your prompt or to open another chatbot with it). Settings and snippets are saved with `chrome.storage.sync`, which Chrome may sync across your own signed-in browsers. The only network request is a version check to `https://raw.githubusercontent.com/lisyoen/ai-chat-easy/main/publish/latest.json`. The optional updater helper runs `git pull` in your own clone and nothing else.

**한국어.** AI Chat Easy 는 브라우저 안에서만 동작합니다. 서버, 분석, 추적이 없습니다. 채팅 입력창 내용은 도구를 쓸 때만 읽습니다(예: 프롬프트 복사, 다른 챗봇으로 보내기). 설정과 스니펫은 `chrome.storage.sync` 에 저장되며 Chrome 이 사용자 본인의 로그인된 브라우저 사이에 동기화할 수 있습니다. 네트워크 요청은 `https://raw.githubusercontent.com/lisyoen/ai-chat-easy/main/publish/latest.json` 버전 확인 하나뿐입니다. 선택 사항인 업데이트 도우미는 사용자의 clone 에서 `git pull` 만 실행합니다.
